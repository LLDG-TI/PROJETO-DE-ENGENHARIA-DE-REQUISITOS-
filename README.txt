# MMG Marmoraria — Catálogo Digital

Arquivos:
- `index.html` — estrutura do site
- `css/style.css` — identidade visual, responsividade e componentes
- `js/script.js` — filtros, busca, seleção de modelos, modal e WhatsApp
- `assets/` — imagens extraídas do catálogo PDF enviado

## WhatsApp
O número principal usado nos botões é `(61) 99992-3919`, conforme o catálogo. Para trocar, edite `whatsappNumber` em `js/script.js`.

Abra `index.html` no navegador para testar.
